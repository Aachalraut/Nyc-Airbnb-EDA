# 🏠 Airbnb EDA & Analysis (Python)

## 🧭 Overview
Airbnb has reshaped the travel and hospitality industry since 2008 by connecting hosts offering diverse accommodations — from private rooms to entire homes and unique stays like treehouses and boats — with travelers seeking flexible, cost-effective lodging worldwide.

This project performs an end-to-end **Exploratory Data Analysis (EDA)** on Airbnb listings data to uncover actionable insights into pricing, host behavior, and market trends.

## 🎯 Objective
This analysis aims to support decision-making for:
- **Hosts** looking to optimize pricing and listing strategy
- **Travelers** seeking the best value stays
- **Business stakeholders** interested in Airbnb's marketplace dynamics

## 📊 Dataset
The dataset includes:
| Category | Fields |
|---|---|
| Listing Details | ID, name, host ID/name, neighbourhood group, neighbourhood, latitude, longitude |
| Accommodation Attributes | Room type, price, minimum nights |
| Review Metrics | Number of reviews, last review date, reviews per month |
| Host Information | Listings per host |
| Availability | Days available per year |

## 🔍 Key Analyses
- **Average Price by Neighbourhood Group** — compared pricing across Brooklyn, Manhattan, Queens, etc.
- **Room Type Preferences** — analyzed distribution of entire homes vs. private/shared rooms
- **Popular Neighborhoods** — identified high-demand areas by listing and review volume
- **Price Trends Over Time** — tracked seasonal and market-driven price fluctuations
- **Price Variability by Borough** — examined spread and diversity of pricing within regions
- **Price vs. Review Count** — explored the relationship between cost and listing popularity
- **Host Activity Analysis** — assessed how multi-listing hosts affect pricing and availability

## 📈 Visualization Techniques
- Correlation heatmaps
- Line plots for price trends over time
- Bar charts & treemaps for categorical distributions
- Scatter plots for price/review/availability relationships
- Interactive charts for dynamic data exploration

## 💡 Key Insights
- **Pricing Strategy:** Hosts can tune prices based on neighborhood, room type, and seasonality to boost occupancy and revenue.
- **Guest Decision-Making:** Clear visibility into which neighborhoods and room types offer the best value.
- **Market Dynamics:** Highlights supply-demand patterns useful for marketing and operations.
- **Host Optimization:** Shows how listing count impacts availability and pricing across hosts.

## 🛠️ Tech Stack
`Python` · `Pandas` · `NumPy` · `Matplotlib` · `Seaborn`

## 🚀 Summary
This project combines statistical analysis and visual storytelling to deliver a comprehensive view of Airbnb's marketplace — turning raw listing data into insights that are useful for hosts, travelers, and analysts alike.
